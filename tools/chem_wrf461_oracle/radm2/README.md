# RADM2 column oracle, WRF v4.6.1

`build.sh WRF_SRC BUILD_DIR [FIXTURE_ROOT]` compiles chem/module_radm.F and
the modules it USEs whole and unchanged at `-O0`, against `stub_radm2.F90`
(the Registry-generated index modules for the radm2sorg package only), then
runs `run_radm2.F90`, which calls `radm_driver` on 12 columns x 24 levels for
two carried schedules and writes one case per call through `oracle_io.F90`
(a byte copy of tools/chem_wrf471_oracle/gocart/oracle_io.F90).

* `SOURCES.sha256` pins every compiled WRF file; a mismatch stops the build.
* Every -O0 object is checked for libmvec `_ZGV*` symbols, and a positive
  control proves the check can fire.
* Fixtures and provenance: `tests/data/oracles/chem/radm2/`.  The port they
  grade is `woof/core/chem_radm2.py` / `woof/core/kernels/chem_radm2.cu`,
  whose arithmetic block is generated by `tools/chem_radm2/transcribe_radm2.py`
  from the same pinned source.
