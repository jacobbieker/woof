# MADE/SORGAM column oracle, WRF v4.7.1

`build.sh WRF_SRC BUILD_DIR [FIXTURE_ROOT]` compiles SORGAM's data modules
whole and copies sorgam_driver's call tree byte for byte from
chem/module_aerosols_sorgam.F into a wrapper module (`routines.list`, after
`prelude.inc`), changing only aeroproc's `isorop=1` to `isorop=0` (the RPMARES
branch; ISORROPIA has no licence grant).  `stub_sorgam.F90` holds the
Registry-generated index modules for the radm2sorg package, a stub `eql3`
(the excluded ISORROPIA branch, never reached) and the service hooks.
`run_sorgam.F90` runs three carried schedules and writes one case per call
(and `run_sorgam_dep.F90` the dry deposition and PM sums, fixtures
`tests/data/oracles/chem/sorgam_dep/`)
through `oracle_io.F90` (a byte copy of the gocart lane's).  `ORACLE_COVERAGE=1`
builds with gcov.

Fixtures and provenance: `tests/data/oracles/chem/sorgam/`.  The port they
grade is `woof/core/chem_sorgam.py` / `woof/core/kernels/chem_sorgam.cu`,
generated by `tools/chem_sorgam/transcribe_sorgam.py` (tools/chem_f2cu).
